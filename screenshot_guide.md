# Screenshot Guide

Use the following screenshots for GitHub and applications. Capture views after running the full pipeline on a representative ticker/date range.

## 1. Dashboard Overview
- What to capture: top of app with title, settings summary, and headline metrics visible.
- Suggested caption: "Interactive dashboard for Transformer-based forecasting, benchmark comparison, and backtesting."

## 2. Forecast vs Actual
- What to capture: "Out-of-Sample Returns: Actual vs [Model]" chart.
- Suggested caption: "Out-of-sample forecast comparison for the selected equity and horizon."

## 3. Benchmark Table
- What to capture: benchmark dataframe with Transformer and all baselines side by side.
- Suggested caption: "Model comparison emphasizing benchmark-based evaluation rather than isolated ML performance."

## 4. Equity Curve
- What to capture: cumulative equity curve chart (strategy vs buy-and-hold).
- Suggested caption: "Transaction-cost-adjusted backtest comparing model-based strategy performance with buy-and-hold."

## 5. Drawdown Chart
- What to capture: strategy and buy-and-hold drawdown figure.
- Suggested caption: "Risk analysis through drawdown tracking during the out-of-sample backtest."

## 6. Project Report / Limitations Section
- What to capture: in-app report section including limitations block.
- Suggested caption: "Built-in report section discussing methodology, assumptions, and limitations."

## Optional Additional Screenshots
- Training vs validation loss figure.
- Reconstructed predicted vs realized price path.
- Backtest metrics table and threshold settings.

## Practical Tips
- Use consistent browser zoom and window size for cleaner gallery layout.
- Prefer a neutral ticker/date range that produces stable, readable figures.
- Save files with clear names: `01_overview.png`, `02_forecast_vs_actual.png`, etc.
- Store screenshots in `screenshots/` and reference them in the README if desired.
